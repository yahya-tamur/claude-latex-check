For a value $a$ at a point $\mathbf{x}$ relative to a chosen origin:

- **First:** $\sum a$, the plain sum.
- **Second:** $\sum a\,\mathbf{x}$, weighted once.
- **Third:** $\sum a\,x^2$ (or the matrix $\sum a\,x_i x_j$), weighted twice.

In the continuous case the sums become integrals, e.g. $\int g(\mathbf{x})\,\mathbf{x}\,dV$.

| Name | Formula | Note |
|---|---|---|
| **A** | $\boldsymbol{\tau} = \mathbf{x}\times\mathbf{y}$ | x |
| **B** | $\mathbf{v} = \mathbf{x}\times\mathbf{z}$ | x |
| **C** | $\sum c_i\mathbf{x}_i = C\,\mathbf{x}_{\text{avg}}$ | x |
| **D** | $D = \sum c_i x_i^2$ | Also ($s = D\beta$) |
| **E** | $\mathbf{w} = \sum d_i \mathbf{x}_i$ | x |
| **F** | $\boldsymbol{\mu} = k\mathbf{A}$ for one case | x |

- **Last.** a series in $1/r$.
